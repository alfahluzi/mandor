# Populated Example

Toko Online is a populated reference for every JSON shape the CLI
manipulates; `scripts/mandor.js` validates it.

Inspect (run from repo root):
  ./bin/mandor --project examples/sample-project milestone list

Dashboard (live server, Ctrl+C stops):
  ./bin/mandor --project examples/sample-project dashboard

`next_ids` must exceed existing IDs; `risk-002` shows post-fix defaults
(`not yet mitigated`, `unassigned`). Start new projects from this tree.
